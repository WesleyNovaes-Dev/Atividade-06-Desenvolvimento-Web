# 🧩 Atividade 06 – Desenvolvimento Web

Este projeto consiste em uma aplicação React com múltiplas funcionalidades acessíveis por uma navegação fixa no topo. As funcionalidades implementadas são:

- ✅ To-Do List  
- ✅ Contador de Cliques  
- ✅ Jogo da Velha  
- ✅ Calculadora  
- ✅ Buscador de CEP  

A interface foi desenvolvida com **React.js**, utilizando **Material-UI (MUI)** para estilização e componentes visuais, além de **CSS modularizado** para ajustes personalizados.

O projeto foi versionado com Git, hospedado no GitHub e publicado online via Vercel.

## 📦 Instalação local

Caso deseje rodar o projeto localmente:

```bash

git clone https://github.com/WesleyNovaes-Dev/Atividade-06-Desenvolvimento-Web.git

# Acesse a pasta do projeto
cd Atividade-06-Desenvolvimento-Web

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
